# 完整数据快速请求（2026-11-11）

按用户要求扩展 `/#api`，沿用 SearchFlow 组件和前置访问门，网页不要求用户配置客户 API 密钥。

## 请求方式

- 新采集：多行关键词（去重）、Web / News / Images / Trending Now 组合来源、14 地区、中英文。每批最多 20 个实际搜索请求，逐个提交执行，各自保留状态和完整结果；Trends 不使用关键词，一批仅请求一次。
- 网页条件：指定域名、精确短语、排除词、PDF/DOCX/XLSX/PPTX、after/before 日期；编译为 Google 查询语法，只应用 Web，不冒充新增上游独立参数。展示最终请求 JSON，单查询含条件最长 300 字符。News 地区/语言组合在提交前校验。
- 公开历史：关键词包含/精确、四来源、结果域名、UTC 采集完成日期（含结束日）、地区、语言、请求状态、每页 5/10/20/50；折叠设备/页码/曾贡献新增链接条件。游标翻页，结果不冒充全库总数。
- 请求 ID：按公开 UUID 读取标准完整记录。结果可按全部/结果/热搜话题/富结果预览，单类别最多预览 100 条；每请求 CSV/JSONL 保留完整字段。历史列表按请求折叠。
- 能力说明与字段目录按需展开；Maps 根据真实运行配置显示未开放。历史热度、搜索量和 AI 答案不开放，城市/设备/深度不作为已实现的新采集参数。

## 实现与隔离

`quick_request_ui.py` 替换界面，`quick_request_http.py` 增加受限的 catalog、history、record、公开记录 export、本人 job data 路由。沿用同源检查、专用头、服务端凭据和签名回执；读历史与按 ID 固定 `scope=public`、`prd-v1`，用户不可注入账户或 own/accessible 范围。公开下载重新检查当前公开可见性，公开与任务回执分域，不能互换。

批次保存在当前标签页 sessionStorage（条件、顺序、固定幂等键和任务回执，不保存内部 API Key）。刷新后显式“继续查看进度”恢复；HTTP 超时重试沿用原幂等键。顺序队列不会绕过后端并发/月额度，停止不删除已完成数据。关闭标签页时尚未提交项不会后台执行；在途任务由服务器继续处理。
