## 已落地能力

### 搜索分析

- 从最近 30 天、最多 200 个历史 Web 请求中读取真实快照，不产生新搜索费用。
- 只比较相同关键词、地区、语言、设备标记、页码、提供方的样本。不同条件样本排除并提示数量。
- 展示最近两次 URL 新增、未出现、实际排名变化、URL 集合重合率。
- 可输入目标域名，查看最近排名、最好排名、出现率和排名时间线；图中的未知排名不连线。
- 域名分布统计“出现过的快照数”，不冒充网站流量份额。缺失排名不填成 11；不把未出现宣称为从 Google 消失。
- 缓存复用按原采样时间去重，不制造虚假的新观察。最新查询只有一个有效快照时明确等待第二次采样。

### 关键词与竞品监测

- 固定关键词、域名、地区、语言，最多 10 个竞品；每空间最多 100 个监测。
- 可选每小时、每 6 小时、每天、每周，显示约 30 天预计用量。
- 创建后默认暂停，点击开始才消耗空间额度。暂停会取消该监测仍在排队/运行的自有任务。
- 定时协调器随 Web 服务启动，每 5 秒协调一次；不是依赖浏览器保持打开。
- 使用持久化任务与数据库协调锁；配额、任务所有权和旧 worker campaign 同一事务提交。
- 监测报告最多读取最近 100 次任务；上游错误显示为错误，不生成假数据。

### 客户 API

- `POST /v1/search` 是异步接口：202 后按返回地址查询 `/v1/jobs/{id}`。
- 支持任务列表、取消、JSONL / CSV 导出、UTC 月度用量、创建与撤销客户密钥、监测创建/控制/报告。
- 规范：`/v1/openapi.json`；真实数据范围：`/v1/capabilities`。
- SHA-256 保存客户密钥摘要；完整新密钥只在生成时返回。浏览器连接只在当前标签页 sessionStorage 中保存。
- 客户请求按所属空间鉴权，不允许跨空间读取/取消任务或撤销密钥；私有 API 任务从公开工作台任务/结果/导出中排除，直接访问私有请求也返回 404。
- 必须提供 `Idempotency-Key`：同参数重放返回原任务，不重复预留或扣用量；同键换参数返回 409。
- 每空间每分钟 60 次 API 请求，独立并发上限；429 返回 `Retry-After: 60`。
- 创建任务预留额度；成功后扣 1 次；失败和取消释放预留；重复完成不重复结算。取消完成前已经发出的供应商请求仍可能产生供应商成本。
- 平台另设 UTC 月度 100,000 个 API 新任务上限，失败仍占此上限，幂等重放不增加。该上限不包括管理员手动采集和旧 worker 内部重试，不能宣称是供应商原始 HTTP 请求或支出的硬上限。
- 不包含在线支付、发票或真实供应商成本账单。

### 数据提供方

- 默认复用原 OpenSERP 和原 worker；保留原始采样时间、实际提供方与缓存标记。
- 可配置 `SERPER_API_KEY` 启用 Serper Web 适配；当前没有配置，不把按钮伪装为可用，也不自动切换到付费提供方。
- Web 当前只开放首屏、地区、英语/中文。News 是 Google News RSS；Trends 是地区 Trending Now RSS，忽略关键词。
- 城市、设备、Google Maps/Shopping 完整模块、AI Mode、关键词历史趋势、精确搜索量未实现；富结果仅返回上游实际提供部分。
- 商业供应商转供许可仍按调研报告逐家确认；本次没有购买或确认任何供应商转售合同。

## 设计与部署

界面延续现有工作台：深蓝导航 `#14263f`、操作蓝 `#315fdb`、正文 `#18243b`、说明 `#66738b`、背景 `#f5f7fb`，成功态 `#18765b`。字体 Avenir Next / PingFang SC；内容左对齐。分析以时间线、变化表和样本分布为主体，避免用装饰指标取代数据。

只新增 `sf_*` 表；不运行历史正文/hash 迁移。复用原连接池和队列；不重建旧 worker、OpenSERP、proxy-relay、PostgreSQL 或 Valkey。Web 服务仅加协调器启动钩子，线上原 `web.py` 的其它差异保留，未整文件覆盖。

## 当前边界与后续阶段

这是可验证的第一阶段产品底座，不是全部竞品能力的复制完成。原代理偶发失败已在真实请求中出现，尚未做成功率、P95、持续压测或生产 SLA 承诺。Serper 等商业后端需配置合法账户和许可后另做真实联调。下一阶段可在此底座上加入批量任务、通知/Webhook、客户成本账本、团队权限与付费模块；不能把这些尚未实现的能力对外销售为现成功能。
