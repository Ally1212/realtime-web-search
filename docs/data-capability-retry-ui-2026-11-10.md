# 失败子集重试网页（本地第十六阶段，2026-11-10）

已把第十五阶段的显式重试接口接入现有“数据任务”工作台。沿用客户 Bearer 与站点会话，不新增许可、不自动执行供应商调用、不部署生产。页面组合模块不会初始化数据库或开启运行时。

## 操作与边界

1. 打开已结算、未取消的关键词量部分成功任务，选择“核验失败子集重试”。只读获取固定父观测、摘要、输入映射和排除理由，再为派生参数读取来源与费用预览；这一步不创建任务或预留费用。
2. 查看失败关键词与原输入位置，显式填写新的费用上限并勾选确认。币种来自预览且不可编辑；预览过期、预算未配置、执行器不可用、费用格式错误或未确认时不能提交。后端仍独立核验权限、预算与计划摘要。
3. 单次点击创建独立计费子任务，提交中禁用相关操作。查看子任务进度或重试关联，可返回原任务；同父观测已有子任务时仅显示读取入口。原成功事实、版本、导出与费用保持独立。

缺失月份、低量、近似零、未出现或已有结果不会推断为失败；只沿用后端明确失败输入合同。Google Ads 未返回词不自动成为可重试失败。

## 请求竞态与未知提交结果

- 重试状态绑定当前连接、任务选择和任务版本。迟到的计划、预览、关系或写回复不能覆盖其他任务；迟到的成功写入也不自动跳转。断开连接会中止页面请求并清空相关内容。
- 新提交意图使用独立幂等键；同一连接、父任务、固定计划与预算保留原键。提交成功后不自动再发，丢失响应或报错后移除表单，提示只读核验；已有子任务可被读取找回。服务端父观测唯一约束仍是最终防重屏障。
- 关键词、状态、完整计划和错误均转义。API 示例只含两层鉴权占位符。手机失败词表格换行而不强迫横向滚动；确认区域和按钮至少44px，保留键盘操作。
