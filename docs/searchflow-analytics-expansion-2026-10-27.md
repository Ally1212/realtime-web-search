# 搜索分析扩展：设计与指标口径

设计延续 SearchFlow：深蓝 #14263f、操作蓝 #315fdb、正文 #18243b、说明 #66738b、背景 #f5f7fb、成功绿 #18765b；Avenir Next / PingFang SC。左对齐，以“数据总览 / 排名与竞品”分层，优先放每日观测和数据缺口，指标用一条可比较的数据栏呈现。

```
时间窗口 / 地区 / 语言 / 更新报告 / 导出
[ 数据总览 | 排名与竞品 ]
数据总览：覆盖与重复 → 每日趋势 → 来源与完整度 → 域名 / URL → 可分页关键词
排名与竞品：关键词 / 目标 / 竞品 / 搜索条件组 → 排名时间线 → 页面留存与变化 → 指标口径
```

总览精确聚合当前筛选窗口中的公开请求，不把前几千条抽样当全量；客户端显示数据生成时间，聚合短暂缓存 60 秒。Web、News RSS、Trending Now 分开说明；仅 Web 使用自然排名。去重链接按已存规范化链接（缺失回退原链接），窗口重复不是流量，更不是无价值采集。UTC 今天仍是不完整日。

详情只比较一个关键词与相同条件组。默认选择样本最多的组，可手动切换。最多读取 1,000 条快照并明确截断；缓存去重。排名均值、波动仅计算实际排名；不存在的排名不补造。首次/最后出现是当前窗口内的观察；标题/摘要变化不是正文变化。

公开只读接口：

- `GET /api/product/analytics/overview?days=30&source=all&region=&language=&keyword_q=&offset=0`
- `GET /api/product/analytics?days=30&query=&domain=&competitors=&scope=&region=&language=`

`scope` 使用报告返回的 `scope_choices[].id`，不跨不同搜索条件比较。详情最多读取最近 1,000 条同条件成功记录，返回截断、排除样本、缓存去重、采样起止和统计口径。News RSS 顺序不作为自然排名，Trending Now 不冒充关键词历史搜索量。

## 数据架构与性能

原始响应在数据库中较大且压缩，直接在每次请求中解压扫描会超过 20 秒。改用可重建的 `sf_analytics_requests`（参数与裁剪快照）、`sf_analytics_items`（结果、话题、报道）和 `sf_analytics_reports`（汇总缓存）；不改原始请求、正文、历史 hash 或采集设置。

初次同步在原数据库服务器通过独立进程完成，39,830 条公开请求用时 228.12 秒。协调器每轮最多增量同步 100 条，仅从已有数据库派生统计，不发起搜索。前端显示 `projection` 同步状态；未完成时明确为部分数据。

聚合事务使用一致性快照；链接以规范化 URL 的 SHA-256 标识去重，与原链接注册表口径一致。冷计算禁用该事务的 JIT，限制工作内存，并串行控制冷汇总。内容汇总按筛选、UTC 日期边界及分析数据版本复用，关键词翻页不重新计算全部链接。内存完整响应最多缓存 60 秒；数据库汇总在分析数据版本或 UTC 边界变化后重算，最多保留 64 份。两个缓存都不保存客户私有结果。

## 真实数据核对与局限

当前公开历史范围为 2026-10-10 02:37:07 至 2026-10-26 09:58:17 UTC，不代表仍在采集。

- 39,830 个公开请求，38,885 成功（含 238 个有效空结果）、945 失败，成功率 97.63%。
- 809,290 条来源基础结果/话题，另有 Trends 报道子项；有效链接记录合计 809,788，去重 522,676，窗口内重复比例 35.46%。
- Web 31,676 请求、257,516 链接记录、184,521 个去重链接；News 8,126 请求、551,494 链接记录、337,824 个去重链接；Trends 28 请求、280 次话题观察、778 条报道链接、332 个去重链接。
- 来源去重之和为 522,677，存在跨来源重复，不能直接相加。News 包装链接有 551,494 条，未解析的包装地址不归入具体媒体域名榜。
- 29,601 个网页查询词中，只有 1,247 个有至少两次成功请求（约 4.21%）；还需核对同条件与缓存，不能声称所有关键词都有趋势。
- 默认历史词 `china` 有 11 个同条件快照、10 次相邻比较、16 个 URL、15 个域名，平均重合率 77.54%，65 次摘要变化事件。只是该样本窗口内的 SERP 展示变化，不代表正文、流量或全网变化。
- 无点击、曝光、真实流量、搜索量或转化数据，未新增这些推断指标。页面标题/摘要首次最后观察不作为发布时间；缺失排名不补成第 11 名。
