# 按单IP产能模板核验当前实测

用户澄清旧数字只是格式模板，本次不将22299、286–297、89、7100当当前事实。核验对象：昨夜纯OpenSERP Google第一页、英文关键词实验的9个完整阶段小时。

## 口径与方法

正文全库URL/content_hash去重、>=500字符，按实验首次关联计数。搜索记录按相同完整小时窗口统计，success仅classification=results。

代理主机按当前私有缓存host归组，枚举同主机18080端口的HTTP/SOCKS5端点哈希，结合既有数据库aliases归组；9个小时全部请求均成功映射（unmapped_attempts=0）。未向外部IP回显服务验证实际出口，host组不能被宣称为独立且恒定的真实出口。健康口径为该小时至少一次搜索返回真实结果，不代表整小时无冷却或全量可用。

## 当前数据

- 9个完整小时：15001篇新正文，9361次尝试、8327次有结果搜索、58406条未跨查询去重返回链接。
- 平均正文1666.78篇/小时，搜索尝试1040.11次/小时、有结果925.22次/小时。
- 80个名义代理主机，每小时实际尝试70–78个，其中35–51个有结果，平均41.22个有结果主机。
- 合计371个“有结果代理主机小时”，成功搜索平均22.44次/主机小时；正文等效摊算40.43篇/主机小时。该正文数字没有逐篇归属至搜索代理的直接证据。
- 最好的单主机完整小时有38次成功搜索；按本轮全池平均正文/成功搜索1.80149折算68.46篇，是条件计算，不是该主机正文实测。
- 每次成功搜索7.014条链接、窗口正文/成功搜索比1.80149；正文完成可能滞后搜索，不能作逐请求严格转化归因。
- 假设80个主机全部达到当前有结果主机的平均表现：80×40.43396=3234.72篇/小时。假设80个全部达到最好38次搜索/小时且全局正文收益不变：80×38×1.80149=5476.53篇/小时。两者均未验证，受代理冷却、全局限速、机器和目标站资源、跨查询重复及抓取滞后影响。
- 实际完整小时范围1399–2010；2000仅一小时，不能称长期稳定。
