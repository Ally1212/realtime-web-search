# SearchFlow 工具界面优化

用户最新要求：不增加商业化；Google 来源使用官方图标，整体品牌、UI 与交互更专业。原业务分析需求继续以数据研究工具为定位，不新增付费、套餐、销售或账户分配流程。

## 设计与审视

沿用 SearchFlow 名称和原数据能力。Google 来源使用官方发布的 Google / News / Trends 原始标识；通用导航和操作使用 Google Material Icons 官方 SVG。资产随页面提供，避免页面运行时依赖外部字体/CDN。Google 标识只标明数据来源，页面不使用“Google 官方平台”的名称。

颜色：正文 #202124，说明 #5f6368，分隔 #e0e3e7，主操作 #1967d2，浅底 #f8fafd，状态绿 #137333。Avenir Next/PingFang SC，标题 26/20/16，正文14，表格13，辅助12。左对齐，工具栏短而清晰，数据区域优先。

```
浅色导航 | 标题 / 数据搜索 / 新建任务
         | 来源快捷入口（官方标识）
         | 分析类型 / 筛选 / 已应用条件
         | 数据报告 + 报告目录 + 导出
```

审视：不使用营销式欢迎页、大面积宣传色和重复装饰卡片。保留表格、结果、图表三种内容形态；用明确的层级与留白组织，不把每项指标都装进等尺寸卡片。

## 实施范围

- 导航、标识、响应式菜单、全局数据搜索、结果密度与链接复制、详情侧栏。
- 分析筛选状态、取消旧请求、忙碌/错误/重试反馈、导出状态、报告定位、图表键盘与悬浮提示。
- API 页面使用工具用语，隐藏账户分配入口，不新增商业能力。
- 不更改采集、正文、平台上传/领取、监测开关，不运行旧数据库迁移。
