## 持续运行观察

短测后，直连通道在持续采集中出现验证码，系统自动冷却该出口并切换已有代理。
2026-09-09 07:02 UTC 左右的快照中，代理轻量通道累计 293 次搜索全部成功，Whale 已确认接收 1,583 篇本次新增内容。
这些数量会继续增长，可在 [统计页](http://localhost:8091/stats) 查看。
这是短期验证，不能推断 24 小时成功率；轻量页面排名也不保证与桌面 Google 一致。

已实现统一计数与限速、独立通道熔断、代理级冷却、真实代理健康指标、跨进程查询租约、深分页缓存、对应语言查询去重、分页续跑、浏览器进程硬超时，以及正文标题提取。
旧游标与累计数据保留；不再使用的查询退出调度，搜索故障不再降低关键词质量分。

## 复现

```bash
docker compose up -d searxng
docker compose --profile whale run --rm --no-deps --entrypoint python collector \
  -m realtime.cli benchmark-free --providers wml_direct
```

`--providers wml --profile private` 测试已有代理；`--resample 已有报告.json` 只重新抽样正文。
完整命令、限制与测试入口见 [README](../README.md)。数据库集成测试使用独立测试库；59 项测试全部通过。
