# 首次真实样本接入单

新增可执行的可信Python单步入口见 data-capability-sample-step-2026-11-10.md；可精确执行一个已有获准排队任务并返回完整ZIP，不消费队列中更早的其他任务。生产启动装配和真实配置依赖仍未完成。

目标是取得真实来源返回，验证保存、客户API及完整导出一致；当前没有真实新域样本。本文不授予采购、来源调用、生产发布或连续运行权限。此前本地测试完成的是实现验证，不能代替本单。

## 当前能用什么

| 数据 | 已有代码入口 | 首次验证内容 | 当前外部依赖 |
|---|---|---|---|
| 历史热度 | realtime/data_capability_serpapi.py: SerpAPITrendsAdapter | 一次批准窗口的series、全部points、尺度、时间与raw逐项一致 | SerpApi账号/Key、该域用途与原文许可、计费单位/账单依据、预算 |
| AIO | realtime/data_capability_serpapi_aio.py: SerpAPIAIOAdapter | 搜索及必要展开、全部回答块和明确引用；没出现回答也如实保存状态 | 同上；预算须涵盖搜索和展开，不承诺一次请求必有回答 |
| AI Mode | realtime/data_capability_serpapi_ai.py: SerpAPIAIModeAdapter | 独立通道的全文、块、引用、普通链接与结束依据 | 同上；不能用AIO结果代替 |
| 搜索量 | realtime/data_capability_google_ads.py: GoogleAdsVolumeAdapter | 一组少量批准关键词、输入映射、合并组及逐月数据 | Ads主体/项目/OAuth/customer/访问级别/用途核验、有效Token、developer token、独立计费依据与预算 |

这些是仓库已有候选路线，不是已采购或已核验的供应商能力承诺。当前未实现可以直接投入生产的来源配置CLI或systemd启动项，不能只设置一个Key就宣告上线。NativeSources可绑定适配器和审批，CapabilityDeployment可初始化独立表、恢复、显式启停与挂载；仍需按获准真实配置编写可信启动装配。

## 最少补充信息

1. 明确先验证哪个域及来源账号；凭据只提供受限文件路径，不在聊天、普通JSON或日志粘贴密钥。
2. 明确租户、许可引用、允许保存/交付用途、原文许可与保留期限；Ads另需核验资产scope和Token有效期。审批格式见 data-capability-native-bindings-2026-11-10.md。
3. 明确本轮总预算/币种、每次调用费用上界、计费单位及实际账单核对方式。没有独立账单依据时不能把配置价格当实际费用，也不能假定免费。
4. 固定一个小样本参数和运行位置。首次不启用自动重试、订阅采集或全站自动开关，不自动推广成七天计划。

## 获得配置后的执行顺序

1. 复核来源官方当前API、许可与账号范围，核对原生适配器请求参数和账单回调；不预先假定现行接口与候选实现相同。
2. 在批准范围内配置独立验证数据库/预算、当前审批与原响应仓；使用独立保管的v3检查点进行恢复准入。不能为方便跳过恢复门禁或复制生产数据。
3. 通过可信启动代码装配一个获准域，显式启停；冻结任务参数、调用总上界和幂等键。执行一次任务后停止来源执行器，不修改生产自动开关。
4. 比较实际源响应、保存事实、类型化API、JSONL/CSV/ZIP：数量、顺序、尺度/月份/引用关系、时间、未知/partial/截断与摘要一致；记录实际调用数和费用。AIO展开失败、无回答或源拒绝不伪报完整。
5. 若失败且费用/调用结果不明，保留待对账状态，不自动再发请求。真实通过仅证明该样本与条件，不代表100series、100关键词、500回答或七天完成。
6. 本地真实样本通过后另行准备最小生产差异包及回退；Whale需正式schema、数据集/来源/字段准入和上传范围后再做accepted与固定版本独立读回，不沿用旧Web单样本授权。
