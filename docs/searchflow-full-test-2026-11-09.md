## 本轮完成的优化

1. **测试可复现**：pytest 固定 `tests/`，排除冻结备份；新增隔离 PostgreSQL/Redis 一键回归与自动清理，避免误连默认数据库。最终一键执行 1,027 项全通过。
2. **采集有边界**：先用四来源样本/导出/私有隔离证据准入；正式任务单页、once、有成功次数上限。按来源控制积压，Web 慢时 News/Images 仍继续；本轮跳过 12 个积压的 Web 投放时刻。
3. **失败不无限占槽**：独立看护以约三分钟批次上限、20 秒轮询停止卡住的批次，本轮两次成功介入。结束时与主采样器同时 stop 的一条请求返回 400，已只读确认同一任务早已 stopped；补上竞态对账测试，不自动重发 stop。
4. **可审计**：写前 intent、逐响应存档、未知写入不重放；停止后排空、按 request ID 去重、CSV/JSONL 校验与 SHA256 清单。相对路径产物写入也已统一转绝对路径。

此前约 178.8 秒的探索试跑单独留档，没有并入正式三十分钟。控制器按来源独立控制、看护启用时点等变化均保留证据；没有改生产 worker 参数做峰值选优。
