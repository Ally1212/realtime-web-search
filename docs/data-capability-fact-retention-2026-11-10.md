# 第二十阶段：事实清除与导出发送前复查（本地候选）

本阶段推进 GOV-04：覆盖新四域观测内容、子记录投影、缓存复用和关联响应仓；尚不等同于完整清除或备份恢复验收。

## 已实现

- 新可信 `FactRetention.erase(tenant,observation_id,reason=...)`。独立墓碑保存租户、观测ID、原事件的SHA256、首次时间及安全原因码；不保存原文或参数。事务内删除全部子记录，清空观测payload/parameters/revision，以不含原事件文字的标记替换event_key；保留ID、原摘要、实体关系和时间作为审计信息。首次清除不被重复调用改写。
- 安装了响应仓时，同事务清除该观测全部关联任务（包括缓存别名）的原响应及元数据，并写入上一阶段响应墓碑。未安装响应仓不自行创建它。任务状态、已结算费用、预算和来源逐次费用账本不重写、不退款或重发。
- 独立墓碑阻止详情、任务事实、子记录分页、投影重建、缓存复用、既有事件再次完成、订阅重领/确认。列表、类型根记录、待交付计数及批次历史排除已清除观测；跨租户仍404。新事实删除的参数仅限观测表，关联任务参数及重试计划没有物理删除。
- 观测读取采用共享行锁；清除采用行更新锁和与完成一致的事件锁。投影重建先取得更新锁再读取，避免读到旧内容后在清除之后重建。并发重复清除只记录一次，失败整笔回滚。
- `purge_expired(tenant,limit=100)` 只选ID，单次1–1000条，有has_more，逐观测事务，可中断后继续；不批量加载大原文。未启用生产定时任务。
- 修复导出竞态：任务、观测和订阅导出在文件生成后、HTTP发送前重新读取事实/批次并核验当前权利、墓碑和固定摘要。清除或撤权发生于生成中时，返回结构化错误，已生成的内存文件不发送。已交付的外部文件无法由本站主动撤回。

## 使用与合同

```python
from realtime.data_capability_fact_retention import FactRetention

retention = FactRetention(configured_capability_data)
retention.erase(tenant_id, observation_id, reason='rights_revoked')
page = retention.purge_expired(tenant_id, limit=100)
# has_more仅表示本轮快照还有候选；继续运行会重新查询，不凭此推测最终清除总数。
```

没有客户删除或恢复接口；可信运维必须使用明确租户和观测ID。OpenAPI仍1.9.0，没有新增事实字段或改动旧字段格式；补充410/404、生成后检查和外部文件边界。capabilities补充本地清除范围与恢复未实现状态，fields的事实字段目录保持原合同。原固定事实导出/订阅清单和哈希规则不变；已清除事实不再输出伪造的空完整快照。

## 验证

独立PostgreSQL覆盖四域、缓存别名、已生成待领批次、ACK拒绝、原事件重放、投影重建、并发清除、批次TTL、跨租户、费用保持和清除失败事务回滚。真实本地双层鉴权客户HTTP覆盖任务/观测/订阅三条导出路径的JSON/JSONL/CSV/ZIP/manifest：生成函数完成后执行可信清除，再验证发送前410而非文件；另验证生成期间撤权。测试保留正常60次/分钟限流，各格式使用独立测试空间，没有放宽产品限流。均为合成事实及来源，无真实收费、平台写入或生产删除。

## 未完成的范围

- 事实墓碑尚无独立签名检查点及备份重放；上一阶段签名恢复只覆盖响应仓。恢复旧事实数据库仍可能复活已删除事实，禁止宣称恢复保护已完整。
- 任务参数、重试计划、订阅筛选/名称、来源账单备注及平台副本没有统一物理清除。任务元数据入口仍可能展示原查询条件，不能把本阶段称为客户完整数据删除。
- 发送前复查与底层socket传输不是数据库原子事务；复查后至发送期间的严格清除屏障及已开始传输的终止尚未实现。已交付外部文件不能召回。
- 未实现来源撤权自动扫描、在途未关联任务按许可整域清除、平台清除证明、已生成磁盘文件撤回、恢复启动门禁及独立检查点外部保管。
- 逻辑字段更新/DELETE不等于PG/WAL/备份/磁盘安全擦除。真实来源许可/Key/费用、金标、正式挂载、各域Whale固定版本读回、规模和七天验收继续未完成。
