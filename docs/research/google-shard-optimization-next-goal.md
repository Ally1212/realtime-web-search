# Google 采集 shard 阶梯压测与长时间稳定性验证

## 目标与现有基线

选择**每实际小时全局去重新增有效正文最高、且 Google 错误率可接受**的 shard 配置，并通过 6–8 小时连续运行验证，最后给出生产 shard 数、RPS、预计每小时产量及 CAPTCHA/transport 风险。

用户提供的 3 shard / 3 小时已完成基线：全局去重新增有效正文 **10,049**，约 **3,350 条/小时**；Whale accepted **7,270**。原始账本及截止时间口径仍待核对。Whale accepted 是独立指标，不与新增正文相加，也不把重复回执计入新增接收。

## 阶梯执行

1. 读取已跑完的 **r8：4 shard / 1 小时**原始账本和报告。以同一统计脚本按各实验实际起止时间计算：全局正文 hash 去重后新增量、每小时产量、Whale accepted、实际 Google 请求数、成功数、CAPTCHA、transport 错误及其他失败；同时检查每个 shard 的状态、时长和配置。与 3 shard 基线比较时，按实际小时归一化，不直接比较 1 小时与 3 小时的总量。
2. 若 4 shard 的全局去重新增正文/小时高于 3 shard，且错误率、冷却和 Whale 待投递没有出现不可接受的恶化，继续做 **6 shard** 等口径限时压测。若增益仍明显、系统资源和错误率允许，再测 **10 shard**；如果增加 shard 使全局产量下降或错误失控，回退到上一有效配置。不得以各 shard 本地新增量简单求和代替全局去重。
3. 在完成的阶梯结果中，以全局去重新增有效正文/实际小时排序；把 CAPTCHA、transport、总失败率、有效搜索产出、Whale 接收与积压、CPU/内存和截止后残留任务作为约束，选出最高且错误率可接受的配置。遇到短时波动或配置变化，补测同口径窗口后再定最优。
4. 对最优配置连续运行 **6–8 小时**。逐小时记录全局新增正文、Whale accepted、实际 RPS、CAPTCHA/transport、冷却时长、进程存活和资源占用；检查后半程产量是否衰减以及 Outbox 是否持续积压。短测外推不能替代长测结果。
5. 输出最终生产建议：**shard 数、每 shard 与总 RPS、长测实得和预计每小时全局去重新增正文、Whale accepted 参考值、CAPTCHA/transport 风险与回退阈值**。建议必须注明实验时间窗口和账本路径。

## 生产建议（基于 r6–r11，2026-09-28）

- **shard 数：6**，每 shard 0.25 rps（目标总 1.5 rps，长测实得 0.39 rps）。
- **预计产量**：冷启动第 1 小时约 4,500 条全局去重新增正文；第 4 小时起稳态约 1,100/小时；7 小时平均 1,899/小时。Whale accepted 参考：7 小时 9,321（1,332/小时）。
- **风险**：CAPTCHA 在第 3–4 小时后升至约 31%（代理池冷却饱和）；transport 错误集中在冷启动阶段（约 32–38%），稳态后 <1%。
- **回退阈值**：CAPTCHA 持续 >35% 或稳态新增 <800/小时时，降回 4 shard（r8 口径 3,642/小时短测）或暂停 6–12 小时让代理池恢复。
- 不建议 10 shard（r10 实测 4,805/小时，低于 6 shard 的 5,155/小时）。
## r12 通宵延伸测试（2026-09-28 23:26 – 09-29 09:02，9.6 小时，代理池热启动）

- 总量：全局去重新增 11,691（1,218/小时），Whale accepted 8,193（853/小时），实际 RPS 0.20，CAPTCHA 29.2%，transport 0%。6/6 shard 完整，无 Whale 积压。
- 逐小时新增：1,805 / 1,025 / 829 / 1,406 / 1,282 / 993 / 1,380 / 953 / 1,315 / 末段 892。无持续衰减，在 830–1,400 之间波动。
- 与 r11 对比：冷启动第 1 小时 4,469 是因为代理池新鲜；r12 直接以热代理池起步，全程即稳态。CAPTCHA 稳定在约 30%，transport 归零——稳态下失败几乎全是 CAPTCHA 冷却。

## 最终生产建议（2026-09-29，依据 r6–r12）

- **shard 数：6**；每 shard 0.25 rps（wml、yield 计划、site×10+recent×2、private 代理、Whale remote-only）。
- **预计每小时全局去重新增正文**：冷启动首小时约 4,500；连续运行稳态约 **1,100–1,200/小时**（r11 后半程与 r12 全程互相印证）。Whale accepted 稳态约 850–900/小时。
- **风险**：CAPTCHA 稳态约 30% 是主要约束（代理池 80 个出口冷却饱和）；transport 稳态≈0。10 shard 不增产（r10 实测更低），不建议。
- **回退阈值**：稳态新增连续 2 小时 <800/小时，或 CAPTCHA 持续 >35%，降回 4 shard 或停跑 6–12 小时让代理池恢复。
- 账本路径：服务器 20.106.103.139，卷 openserp-pipeline_experiments-data，目录 r6|r7|r8|r9|r10|r11|r12-shard*；汇总 JSON 在 docs/research/r6..r12-*-summary-*.json。
