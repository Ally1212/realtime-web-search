# SearchFlow 完整数据能力需求文档

版本：1.0；日期：2026-11-10；状态：需求基线，待按工作包实现及验收。

## 1. 总目标与本轮范围

以现有 SearchFlow 为基础，完善 Google 多域数据获取能力，使每项功能都能真实采集、完整保存、正确去重与版本化，并通过客户 API 查询、订阅和完整导出。优先完成：历史热度曲线、关键词搜索量、完整 AI 回答。

本轮“历史热度曲线”指新任务从真实来源取得历史时间序列；不等于处理现有旧库。现有历史数据不回填、不批量补新闻链接、不重写原响应或历史贡献。不新增排名、竞品、预测、机会评分、AI 报告等数据分析；已有分析能力保留。

用户已确认功能建设方向。本文件整理需求，不代表三项已实现、采购已发生或生产持续运行已开启。外部凭据、预算和来源未确定时，继续可独立完成的契约、实现和隔离测试，具体依赖准确登记。

## 3. 当前能力与完整缺口清单

状态定义：已上线=对应范围有发布证据；部分完成=仅部分字段、框架或样本成立；未接通=没有对应真实生产数据链路；待验收=实现或局部验证不足以通过完整标准。

| 编号 | 数据能力 | 当前状态 | 本轮处理与出口 |
|---|---|---|---|
| BASE-01 | Web 自然结果：标题、摘要、URL、自然位置、源绝对位置 | 基础已上线 | 保留；新任务补真实搜索上下文、源版本和时间依据 |
| BASE-02 | News 元数据、RSS日期、发布者、真链接解析 | 新采集基础已上线；旧数据大量包装链接 | 保留新任务解析、限速和失败证据；旧历史不补 |
| BASE-03 | Trending Now 热点、原始量级标记、相关报道 | 已上线 | 与历史数值曲线分域，不能混用 |
| BASE-04 | Images 图片地址、来源页、尺寸及顺序 | 基础已上线 | 保留；缩略图等缺失不伪补，不默认下载原图 |
| PRI-01 | 历史热度曲线、区域兴趣、相关词 | 数值来源未接通 | 本轮优先；核心为真实历史序列，扩展字段按源能力返回 |
| PRI-02 | 关键词搜索量、月度历史、商业字段 | 真实来源未接通 | 本轮优先；先搜索量，CPC等只返回获准实际字段 |
| PRI-03 | AIO / AI Mode 完整回答与引用 | 仅部分富结果；完整域未接通 | 本轮优先；两通道独立能力、状态和验收 |
| EXT-01 | GSC Search Analytics / Bulk、URL Inspection | 有局部合同/实现，真实资产未接通 | 后续条件域；仅获准资产只读 |
| EXT-02 | GA4 报表 / BigQuery 事件 | 有局部合同/实现，真实资产未接通 | 后续条件域；报告与事件分别建模 |
| EXT-03 | Ads 经营报表 | 有局部合同/实现，真实资产未接通 | 后续条件域；与关键词量分开准入 |
| EXT-04 | Merchant 商品/表现报表 | 真实资产未接通 | 后续条件域；只读、不发布商品 |
| EXT-05 | Local / Maps 网格、Places / GBP、评论 | 正式来源与字段用途未接通 | 后续条件域；不把少量评论当全量 |
| EXT-06 | 出版者正文、canonical、作者、修改时间 | 基础SERP未覆盖；正文关闭 | 独立条件域，本轮不启动正文采集 |
| GOV-01 | 来源、用途、字段与保留期限登记 | 框架部分完成 | 三项新来源必须补真实配置及执行门禁 |
| GOV-02 | 请求/观测身份、重复出现、修订与源时间 | 基础及增强字段部分完成 | 对三项扩展，覆盖同值新观测与重试幂等 |
| GOV-03 | Whale 正式schema、终态、固定版本独立读回 | 单样本完整证明；全域未验收 | 三项逐域对账；本地成功与平台成功分别展示 |
| GOV-04 | 撤权、到期、清除、备份恢复与tombstone | 局部实现/隔离验证 | 全链路仍待真实平台验收 |
| GOV-05 | 七天端到端、真实规模、费用与恢复验收 | 未完整完成 | 分阶段验收；现有归档巡检不能替代 |
| API-01 | 两层鉴权、异步任务、完整读取/导出、客户拉取订阅 | 现有四来源已上线 | 三项扩展必须同步进入主客户API |
| API-02 | Webhook、主动推送、浏览器跨域直接调用 | 未开放 | 记录为可选后续能力，本轮不自动扩大范围 |

分析域（排名/竞品、品牌/情感、事件聚类、预测、经营归因、AI研究报告和跨平台洞察）不进入本轮实施；不删除现有功能。

## 4. 统一数据链路

每项新能力必须贯通：能力查询 → 参数校验/来源准入 → 费用预估与额度预留 → 幂等任务 → 源调用/限流/重试 → 许可内原始响应保存 → 标准化事实 → 去重与版本 → 任务终态 → API/导出/订阅 → 平台回执及独立读回。

客户任务完成、本地事实保存成功、平台accepted、固定版本readable是不同状态。平台交付未完成时不能伪报已读回；平台是否为该任务完成门槛须在冻结合同中写明。

### 4.1 公共字段

- 身份：tenant_id、job_id、request_id、observation_id、entity_id、source/provider、原生task/result ID、schema/API/parser版本、payload_hash。
- 条件：原始query或prompt、term/topic、国家、语言、device、location及精度、surface/channel、请求深度、源实际生效参数；不支持的参数拒绝或明确降级，不能静默忽略。
- 时间：scheduled_at、requested_at、received_at、source_observed_at、stored_at、平台ingested/readable时间；源时区、时间依据与未知原因分开。
- 完整性：requested/returned/saved数量、is_partial、is_truncated、分页结束依据、缓存命中及原始观测时间、cache_age、源错误与警告。
- 权限及费用：asset/grant/license、允许用途、保留期限、计费单位、币种、费用、重试费用与退款/额度结算状态。
- 来源原字段：许可范围内保留原始结构及引用/hash；敏感字段脱敏有明确标记，不声称字节级无损。

字段状态沿用 available、true_zero、unknown、not_observed、not_covered、outside_observed_depth、source_error、expired。缺失、受阈值保护、低量、四舍五入、估算、截断分别保留依据；null不能补0。

### 4.2 去重和修订

- URL对象去重不删除每次query/run/item出现记录。不同来源、位置、设备、通道仍有独立观测。
- 同一任务重试复用事件身份；新真实观测即使数值或回答相同仍保留。缓存复用关联原观测，不冒充新样本。
- 数值点按来源、租户/资产、条件、series、时间区间、scale及revision定位；修订保留版本和supersedes关系。
- 同一幂等键不同参数报冲突；同事件不同payload拒绝或走显式修订，不静默覆盖。
- 新域使用独立模型/表及可重建投影，不将曲线点、搜索量或AI回答硬塞为普通URL结果；不触发旧正文/hash迁移。

## 5. PRI-01 历史热度曲线

### 输入与输出

输入至少包含关键词或topic ID、国家/地区、起止时间、类别和搜索类型；语言、细分地区、时区、粒度、多词比较等按真实来源能力声明。

输出包含series_id、term_or_topic、原始词与源解析对象、requested/effective window、粒度、地区、搜索类型、category、source timezone、scale_id、归一化方式、比较组/批次；每点有period_start/end、value、状态、partial、revision及源引用。

### 必须实现

- 从真实可用来源获取历史序列，支持查询、持久化、点分页、完整JSON/JSONL/CSV及拉取订阅。
- 明确相对指数、同尺度指数和估算绝对量的测量性质。Trending Now approx_traffic不得转成历史曲线。
- 不同窗口/批次的0–100值不直接拼接；无法证明可比时保存为独立series。可比性由源依据决定，不通过本轮分析算法“修正”。
- 处理空序列、真实0、低量、未覆盖、部分周期、窗口裁剪及历史修订；重取不抹掉旧版本。
- 区域兴趣、related top/rising、breakout是独立结果集；源不支持时明确未覆盖，不阻塞已验证核心序列。

### 验收

固定真实响应与标准点、API、导出逐项一致；跨窗口、跨比较组、低量/partial/修订反例通过。按总PRD目标验证100条真实series；不足则仅发布已验范围，不用合成测试冒充真实来源验收。

## 6. PRI-02 关键词搜索量

### 输入与输出

输入：关键词列表、国家/位置、语言、网络及请求月份范围；匹配/合并规则由来源明确。

输出：requested_query、returned_text、close_variant_group、monthly_volume或平均量及其统计窗口、逐月year/month/value、unit、measurement_type、rounded/range/censored标记、国家/语言/网络、来源及观测时间。若真实源提供，可返回competition、competition_index、CPC、bid percentiles、currency、micros和估算字段。

### 必须实现

- 批量去重请求与输入映射并存，每个输入均能找到返回项、合并组或无数据原因；源合并close variants时不拆成伪精确逐词量。
- 历史月份缺失与0区分；均值保留源统计窗口，不拿Trends相对指数推算搜索量。
- SEO难度、广告竞争度、点击价和搜索量分别命名；micros不按普通货币直接展示，币种不可混加。
- 批次上限、配额、部分失败及实际计费单位可查；重试只重试失败子集，避免重复计费与成功结果丢失。
- Ads来源须核验当前主体、项目、OAuth、customer、访问级别及适用用途；供应商路线同样确认数据性质和交付范围。候选来源不等于已采购或已准入。

### 验收

真实关键词返回、月份、合并组、单位和源响应逐字段一致；中文/英文、近似词、无数据、0、范围值、批量部分失败、币种及舍入负例通过。记录至少100关键词的真实覆盖；双市场/双设备等总PRD要求仅在适用域验收，不给搜索量虚构设备维度。

## 7. PRI-03 完整 AI 回答

### 输入与输出

输入：query/prompt、明确的aio或ai_mode通道、国家、语言、设备/位置、可选会话/轮次及展开请求；后续对话仅在来源真实支持且已验收时开放。

输出：answer_id、run_id、channel、原始prompt及版本、turn/repeat_group、完整answer_text与有序结构块、明确引用citation列表、citation与文本/块的关联、目标URL、来源标题、源引用角色、展开状态、缓存、源时间、截断/部分状态。model仅在源明确提供时记录。

### 必须实现

- AIO与AI Mode分别接入、分别宣告能力；普通SERP摘要、PAA和生成模型API不替代这两个通道。
- 支持源所需二次展开和短效token流程；token不进日志/导出。过期、展开失败、未出现回答、拒答、部分回答分别记录。
- “完整”指已成功取得源在该次批准观测中提供的全部可获取回答块及明确引用，且分页/展开结束有依据；只能拿到片段时标partial，不能叫完整成功。
- 区分普通链接与明确引用；保存源给出的引用顺序及文本关系，不通过数组位置或相似内容猜引用角色。
- 保留格式/表格/列表的结构化表示及全文文本；源缺失的引用、模型、位置不伪补。外链不自动抓正文。
- 支持回答、块、引用分页查询、完整导出及订阅；同文新观测保留，缓存复用不冒充新回答。
- 本轮不做品牌mention识别、情感、引用影响力、AI可见性评分或AI报告。

### 验收

分别以真实AIO/AI Mode响应校验回答全文、块顺序、引用角色/映射与导出；覆盖未出现、拒答、普通链接、二次展开过期、缓存、部分成功及超长回答。总PRD的500回答金标作为完整验收目标；当前仅做文本/结构/引用数据核对，分析标签金标暂缓。

## 8. API 全覆盖要求

### 8.1 已有能力与兼容

主客户入口沿用 `/v1/openapi.json`、`/v1/capabilities`、`/v1/data/fields`、`/v1/search`、`/v1/jobs`、`/v1/data/requests`、`/v1/data/export`、`/v1/data/subscriptions`。研究目录 `/v1/google/*` 当前未连接项不能冒充主客户能力。

继续两层鉴权：X-SearchFlow-Access-Key + 客户Bearer；own/public/accessible保持现有隔离。无管理权限的客户不能改全站开关。密钥不能嵌入前端公开代码；不默认开放跨域。

### 8.2 新能力接口合同（拟定，实施前冻结）

| 用途 | 拟定路径/扩展 |
|---|---|
| 提交三类任务 | `POST /v1/data/jobs`，capability=`trends_history`、`keyword_volume`、`aio_answer`或`ai_mode_answer` |
| 任务列表、状态、进度、取消 | 复用并扩展`GET /v1/jobs`、`GET /v1/jobs/{id}`、`GET /v1/jobs/{id}/progress`和既有控制路径 |
| 完整任务数据及导出 | 扩展`GET /v1/jobs/{id}/data`、`GET /v1/jobs/{id}/export` |
| 新域观测统一列表/详情 | `GET /v1/data/observations`、`GET /v1/data/observations/{id}` |
| 曲线与点 | `GET /v1/data/trends/series`、`GET /v1/data/trends/series/{id}/points` |
| 搜索量明细 | `GET /v1/data/keyword-volumes`、`GET /v1/data/keyword-volumes/{id}` |
| 回答、块和引用 | `GET /v1/data/ai/answers`、`GET /v1/data/ai/answers/{id}`及`/blocks`、`/citations` |
| 固定版本导出 | 扩展`GET /v1/data/export`，新增domain/capability及版本过滤 |
| 增量交付 | 扩展`/v1/data/subscriptions`的领域、事件类型与字段目录 |

这些路径是合同提案，不声称已上线。冻结前检查现有路由、schema与命名冲突；新通用data jobs不替换旧search。新域可查询筛选字段、排序、分页、边界及限额必须写入OpenAPI，不要求每域支持无意义的device/URL筛选。

### 8.3 通用行为

- 创建必须幂等，202只代表受理；源不支持/未准入返回结构化错误，不能202后永久空转。已执行计费、取消时在途请求和额度结算规则明确。
- 返回schema版本、来源、条件、时间、coverage/quality/limitations、next_cursor/has_more及可用性；游标绑定租户、筛选和排序，固定快照导出标明版本。
- 任务状态与源结果状态分开；支持部分成功的任务需列成功/失败子项，客户端可定位重试范围。
- JSON、JSONL、CSV/ZIP必须能完整表达时间点、月度值、回答块和引用，不塞入旧7/14列简版合同。CSV长文本及公式转义有说明；manifest含数量、范围、截断、字段版本和SHA256。
- 订阅保留暂停默认值、now/history、领取重试、文件校验及确认后推进。事件区分新观测与修订，实体去重不丢修订；不以new_urls表达数值点或AI回答。
- 每项功能必须同时更新主OpenAPI、capabilities、fields、调用/轮询/下载示例、错误码、订阅与导出合同、测试及发布记录；网页可用但API缺失不算完成。
- 旧源枚举和现有客户继续兼容。需要破坏性变化时新增版本，不改旧ID/hash或重排旧平台事件。

## 9. 网页操作范围

在既有非商业化研究工作台增加三项数据任务入口、有效参数、来源/估算费用预览、任务状态、原始事实查看、分页、下载及复制完整鉴权API示例。沿用品牌、组件、访问门和手机布局。

曲线功能允许按真实序列显示基础时间曲线及数值表，属于数据呈现；不添加增长解读、预测、归因或建议。AI显示保存回答与来源，搜索量显示源值与测量性质。字段缺失、失败、未覆盖和部分数据应可见，不输出假0或假完整。

## 10. 可靠性、权限、成本与平台

- 逐提供方/账号/资产配额排队，遵守Retry-After、指数退避和最大重试窗口；源不可用可暂停，只有已准入且条件语义匹配的来源才能显式切换。
- 日/月预算及任务最大费用先冻结；实际计费与本地额度分账，重试、分页、展开和存储均有单位。不能把旧搜索额度直接套到所有新域而不定义规则。
- 权限在任务创建、执行、缓存复用、列表、详情、导出、订阅重领/确认时检查。跨客户同词/同URL/同回答不得泄露私有事实。
- 来源权利/到期、撤权、取消影响在途、spool、投影、缓存、平台及已生成下载；备份恢复应用tombstone，已交付外部文件的清除责任与不可主动撤回边界明确。
