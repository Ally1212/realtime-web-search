# 面向用户的搜索数据工作台

## 用户主线

网站面向需要搜索资料、跟踪新闻、发现热点并使用结构化数据的人。主流程为：选择内容 → 创建任务 → 查看结果 → 导出或同步。自动采集属于内部供给功能，不提供用户入口、状态、配置或任务列表筛选。后台 API 与运行开关保持原样。

参考 [Apify Google Search Results Scraper](https://apify.com/webdatatools/google-search-scraper) 的输入、运行、结果、导出流程，以及 [Browse AI](https://www.browse.ai/extract) 的无代码数据工作流；只参考信息组织，不复制其功能承诺或品牌。

## 页面与能力映射

| 页面 | 用户操作 | 保留的能力 |
| --- | --- | --- |
| 概览 | 开始新任务、浏览最新数据 | 最近 24 小时去重新增链接、真实结果；健康度、来源统计、异常按需展开 |
| 新建任务 | 选择内容、填写范围、确认创建 | Web/News/Trends 可组合，关键词、单次/持续、页数、地区、语言、单次搜索上限、保存待启动、加入 Whale 队列 |
| 采集任务 | 查看进展、查看结果、控制任务 | 筛选、分页、启动/暂停/继续/停止、完成原因、参数与异常详情；只列用户任务 |
| 数据集 | 检索、筛选、导出数据 | 来源、关键词、任务选择、日期、请求状态、新链接；结果/请求视图、分页、CSV/JSONL、取消导出、请求 JSON 下载 |
| 平台同步 | 上传已有链接、处理平台任务 | 上传开关、平台领取开关、筛选入队、保存待上传、暂停/继续/停止/重试、分页、可读回执与原始字段 |
| 数据偏好 | 了解数据范围、设置正文偏好 | 可选正文开关；来源限制说明与历史正文/实验归档入口 |

## 数据语义

- Web：标题、链接、摘要、自然排名和查询信息。
- News：标题、新闻链接、媒体、发布时间；RSS 顺序不称为 Google 排名，未解析跳转保留标记。
- Trends：地区当前热门话题、上游搜索量标记和相关报道；不提供按关键词的历史热度曲线。纯 Trends 禁用关键词并发送空关键词数组。
- 三来源保留采集时间与原始字段；缺失为未知，重复结果保留查询记录，新增链接按历史去重。单轮搜索数为计划，不承诺严格限制重试次数；单次预算仅在单次模式发送。
- queued 表示平台已入队，accepted 表示接口已接收，不冒充最终业务入库或索引。

## 交互与视觉

深蓝导航、白色数据区域、蓝色操作按钮；创建与列表分离，采用三步流程与用途快捷入口。侧栏即时显示所选数据源提供的字段。确认页展示关键词、来源、模式、地区、语言与页数。任务编号和 JSON 收入详情，回执先显示链接、中文状态、尝试次数与失败原因。适配手机、键盘焦点与减少动态效果偏好。

修正原页面把多行关键词当作反斜线 n 拆分的问题；提交与预估均去重。用户偏好保存只发送 content_fetch_enabled，不发送内部供给设置。

## 本地预览与验证

`python scripts/preview_serp_ui.py` 在 127.0.0.1:8094 提供当前工作树页面，默认通过本机 8093 的 SSH 转发读取生产 GET API。拒绝全部 POST，不启动 worker、不初始化数据库。生产冻结版本没有被替换。

浏览器自动化脚本：`scripts/serp_ui_smoke.js`，通过 Playwright CLI 的 run-code 执行。数据读取与 CSV 导出使用真实数据；任务创建和控制使用浏览器隔离模拟，不验证真实后端持久化或真实 worker 执行。

证据位于 `output/playwright/`：桌面/手机截图、smoke-results.txt、sync-smoke-results.txt、导出文件。附加平台测试模拟上传队列、控制、回执、偏好写入，同时验证真实请求分页与 JSONL 导出。

后端相关 unittest：54 项中 17 项通过，37 项因未配置 TEST_DATABASE_URL 跳过；不宣称数据库集成测试通过。

最终浏览器验收：主流程 24 项、平台与请求流程 9 项，共 33 项通过；任务及上传写操作均为隔离模拟。主流程无 JavaScript 异常，6 个页面在 390px 宽度无页面横向溢出。大批量导出支持取消，避免持续等待没有退出入口。
