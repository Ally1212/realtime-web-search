# 面向用户的搜索数据工作台

## 用户主线

网站面向需要搜索资料、跟踪新闻、发现热点并使用结构化数据的人。主流程为：选择内容 → 创建任务 → 查看结果 → 导出或同步。自动采集属于内部供给功能，不提供用户入口、状态、配置或任务列表筛选。后台 API 与运行开关保持原样。

参考 [Apify Google Search Results Scraper](https://apify.com/webdatatools/google-search-scraper) 的输入、运行、结果、导出流程，以及 [Browse AI](https://www.browse.ai/extract) 的无代码数据工作流；只参考信息组织，不复制其功能承诺或品牌。

## 页面与能力映射

| 页面 | 用户操作 | 保留的能力 |
| --- | --- | --- |
| 概览 | 开始新任务、浏览最新数据 | 最近 24 小时去重新增链接、真实结果；健康度、来源统计、异常按需展开 |
| 新建任务 | 选择内容、填写范围、确认创建 | Web/News/Trends 可组合，关键词、单次/持续、页数、地区、语言、单次搜索上限、保存待启动、加入 Whale 队列 |
| 采集任务 | 查看进展、查看结果、控制任务 | 筛选、分页、启动/暂停/继续/停止、完成原因、参数与异常详情；只列用户任务 |
| 数据集 | 检索、筛选、导出数据 | 来源、关键词、任务选择、日期、请求状态、新链接；结果/采集记录视图、分页、最终数据 CSV/JSONL、取消导出、字段解释 |
| 平台同步 | 上传已有链接、处理平台任务 | 上传开关、平台领取开关、筛选入队、保存待上传、暂停/继续/停止/重试、分页、可读回执与失败原因 |
| 数据偏好 | 了解数据范围、设置正文偏好 | 可选正文开关；来源限制说明与历史正文/实验归档入口 |

## 数据语义

- Web：标题、链接、摘要、自然排名和查询信息。
- News：标题、新闻链接、媒体、发布时间；RSS 顺序不称为 Google 排名，未解析跳转保留标记。
- Trends：地区当前热门话题、上游搜索量标记和相关报道；不提供按关键词的历史热度曲线。纯 Trends 禁用关键词并发送空关键词数组。
- 三来源保留采集时间与原始字段；缺失为未知，重复结果保留查询记录，新增链接按历史去重。单轮搜索数为计划，不承诺严格限制重试次数；单次预算仅在单次模式发送。
- queued 表示平台已入队，accepted 表示接口已接收，不冒充最终业务入库或索引。

## 交互与视觉

深蓝导航、白色数据区域、蓝色操作按钮；创建与列表分离，采用三步流程与用途快捷入口。侧栏即时显示所选数据源提供的字段。确认页展示关键词、来源、模式、地区、语言与页数。任务范围和已保存字段收入详情，回执先显示链接、中文状态、尝试次数与失败原因。适配手机、键盘焦点与减少动态效果偏好。

修正原页面把多行关键词当作反斜线 n 拆分的问题；提交与预估均去重。用户偏好保存只发送 content_fetch_enabled，不发送内部供给设置。

## 最终保存数据优化（2026-10-13）

结果卡片明确显示搜索摘要、最终链接所属网站、自然排名或新闻列表顺序、发布时间。“查看已保存数据”逐项展示值和中文解释：标题、结果链接、搜索摘要、链接所属网站、媒体、排名/新闻顺序/搜索量标记、关键词、搜索地区、搜索语言、采集时间、发布时间、搜索页码、历史首次发现。补充字段与 Trends 相关报道可继续查看。搜索摘要不等于文章全文。

链接网站从最终 URL 解析，不沿用上游错误的 google.com 标记；媒体、作者、发布时间缺失明确为未知，不从摘要日期或网址推断。地区表示实际发送给 Google 的地区，不表示文章来源国家。新闻列表顺序不是 Google 自然排名；Trends 保留热门话题与报道的区别。

用户页面移除请求 JSON 详情和请求 JSON 下载。采集记录展示成功状态、已保存结果数及新链接数，并可查看对应的最终结果。平台回执以字段表解释 queued 等状态。CSV 使用中文列名，导出最终结果字段，无请求 JSON 列；JSONL 仍导出已保存结果记录。原 API 默认行为兼容，新增 view=user CSV 视图，不涉及数据库迁移。

真实中文验收通过生产网页创建“中美关系”“中美贸易”，均采用美国地区、中文语言、一页、单次搜索上限 1，未加入上传队列。读取保存的实际搜索参数确认 gl=us、hl=zh：前者保存 8 条结果、8 个历史新链接；后者保存 8 条结果、7 个历史新链接，共 16 条结果、15 个新链接。两任务各执行一次成功搜索，并已手动停止。证据：output/playwright/cn-us-persisted-data.json。

限制：当前生产冻结 worker 未在上述单次任务成功后自动结束，因此不能宣称生产单次生命周期验收完成。工作树包含单次完成逻辑，生产冻结版本仍未升级；本轮没有部署生产 worker，也未开启内部持续采集、正文、平台上传或平台领取。浏览器中的任务控制、平台控制和偏好写入为隔离模拟，不能当作真实平台入库验收。

本轮后端验证使用临时独立 PostgreSQL（127.0.0.1:55438）：test_serp_presentation、test_serp_console、test_serp_collection、test_whale_serp 共 57 项通过，无跳过。生产数据库未用于这些测试。

本轮最终浏览器验收共 44 项通过：主流程 24 项、真实中文保存字段及下载 9 项、平台/偏好/采集记录流程 11 项。News 与 Trends 使用真实历史数据读取；上传、任务控制和偏好写操作采用浏览器隔离模拟。中文结果单条 CSV 与批量 CSV（8 条）逐项核验地区、语言、链接网站及列结构；JSONL 核验为最终结果数据而非请求响应。六个页面及保存数据详情在手机宽度无页面横向溢出。主流程无 JavaScript 异常。证据：smoke-saved-results.txt、saved-cn-saved-results.txt、sync-saved-results.txt、saved-data-cn-us-desktop.png、saved-data-cn-us-mobile.png。
